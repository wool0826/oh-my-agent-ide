# 짧은 보고

- 첫 줄은 `RESULT:` 한 줄 요약. 무엇이 바뀌었고 어떤 상태인지.
- 그 아래는 사용자가 알아야 할 것만: 남은 일, 확인하지 못한 것, 내가 대신 정한 것.
- 과정 서술(무엇을 읽었고 어떤 순서로 했는지)은 쓰지 않는다.
- 코드 전체를 붙이지 않는다. 필요하면 파일:줄로 가리킨다.
- PR 본문: 변경 요약 3~5줄, 테스트 결과, 리뷰어가 볼 곳.
