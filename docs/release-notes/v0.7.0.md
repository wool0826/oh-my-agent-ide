## Before you install

- **The installers are unsigned.** No signing certificate is set up yet.
  - Windows: SmartScreen shows "Windows protected your PC". Choose More info → Run anyway.
  - macOS: the dmg is ad-hoc signed and not notarized, so macOS blocks the first launch. Open System Settings → Privacy & Security → Open Anyway, or run `xattr -dr com.apple.quarantine "/Applications/Oh My Agent IDE.app"`.
- **Apple silicon only on macOS.** No Intel build is made.
- **Not verified by hand.** The release was prepared before anyone ran the hands-on real-use checklist (`docs/REAL-USE-CHECKLIST.md`), and none of its result cells is filled in:
  - all 17 `real` rows: real tasks, PRs on GitHub, Jira, both accounts, ChatGPT and updating from 0.6.2 (8.2);
  - all 12 `win` rows: installer, tray, notifications, sound, global shortcut, Narrator and the OS theme;
  - the `mac` row (8.3). This version has not been run on a real Mac.

  The 15 `e2e` rows run with fake agents in CI on Windows and macOS, and they pass.

## What's new

### Workers and the Dispatcher
- **See what each Worker is doing.** The Running sidebar shows each Worker's steps as a stepper, plus failed, queued, waiting and stalled states. Workers waiting on subagents or on a background test or build show as running.
- **A look back.** A Worker's Summary tab shows time, waits and permission decisions for each task. Its "This week" view covers all Workers for the last 7 days: spend, successes, CI retries and time spent waiting for you.
- **Warnings about overlapping files.** When a new task names files that work in progress is already changing, the Dispatcher is warned.
- **Mock-ups before new screens.** A request for a new screen first gets two or three mock-ups to choose from. UI changes are reported with before/after screenshots.
- **Less lost context.** A Worker is compacted before its next task, not when a task ends. `/compact` is told what to keep.
- **claude.ai artifacts.** Dispatcher and Worker sessions can publish and read claude.ai artifacts and answer comments on them. You can turn this off in Settings.

### Chat
- **Replies under what they answer.** A reply to a report or a Dispatcher message hangs under it as a branch. The separate thread panel is gone.
- **Run a command from the chat.** Start a line with `!` to run it with your shell profile loaded. Its output goes to the Dispatcher. Scripts you save in the right sidebar run with one click.
- **Side terminal and side question.** A terminal and a side question (asked outside the Dispatcher's context) dock under the chat. Both can be resized from their edges.
- **Better text handling.** Markdown renders links, nested lists and strikethrough. Pasted files attach like dropped files. Memos can span several lines. Each Worker keeps its own draft. Ctrl+F finds messages. Korean IME syllables stay whole while typing.

### Decisions, the inbox and notifications
- **Clearer decision cards.** Cards show the kind, the age, the slot clock and why a permission is needed. You can answer them from the keyboard, and the buttons stay in place.
- **Swipe to clear.** Clear Inbox and Notifications rows by swiping sideways, with a two-finger touchpad swipe or a drag.
- **Task-end notifications.** A notification fires when a task ends, with its own switch and sound and a link to the result.
- **Faster merge notices.** Merged PRs are noticed within seconds. A dimmed Merge button says what it is waiting for.

### Safety
- **Permission rules cover every shell.** The always-ask rules (force push, `gh pr merge` and the rest) and "Allow for this task" now apply to PowerShell as well as Bash. They match on the command's words, so variants like `git -C repo push --force` are caught.
- **Crash recovery.** Crashes are written to `crash.log` and the state is saved at once. A window that dies is reopened, and the next launch tells you if the last run ended abnormally.
- **Safer saved state.** The state file now has a format version. A future format change keeps a copy of the file first. A file saved by a newer version opens read-only.
- **Safer archiving.** Archiving, removing a repository and settling PRs no longer lose work in progress.

### Layout and look
- **Responsive layout.** Both sidebars can be resized by dragging. The right sidebar can grow to 960 px and splits into a list and a detail pane from 560 px. In narrow windows the chat stays wide and the window controls stay clear of the layout.
- **Usage display.** The usage rings read both windows (5 h outside, 7 d inside) for every account and refresh on an interval you choose. A used-up ring shows its reset time.
- **One design system.** Buttons, segmented controls, menus, pills, meters and tooltips now share one design. Selected items are marked with a ring instead of a fill.
- **Keyboard and screen readers.** Arrow keys work at every width, focus is marked apart from selection, and fields and landmarks are named for screen readers.
- **First run and platform fixes.** First-run steps appear on the first launch. Settings are aligned. The Windows taskbar shows the app's own icon. `gh` and other CLIs are found on macOS when the app is opened from the Dock.

### Repositories and automations
- **Local-only repositories.** You can register a repository without a remote, and adding a repository no longer hangs.
- **Edit automations from their cards.** Do-not-disturb hours show in the sidebar.

### Under the hood
- **Release builds from a tag.** A tag builds both installers on GitHub Actions. Signing turns on once its secrets exist (`docs/RELEASING.md`).
- **Steadier CI.** The end-to-end tests run in three shards per system, flaky tests wait for conditions instead of fixed delays, and failed flows keep screenshots.
- **Faster logs.** Large Worker logs are read from the end, so opening and searching them no longer blocks the app.
