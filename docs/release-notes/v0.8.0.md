## Before you install

- **The installers are unsigned.** No signing certificate is set up yet.
  - Windows: SmartScreen shows "Windows protected your PC". Choose More info → Run anyway.
  - macOS: the dmg is ad-hoc signed and not notarized, so macOS blocks the first launch. Open System Settings → Privacy & Security → Open Anyway, or run `xattr -dr com.apple.quarantine "/Applications/Oh My Agent IDE.app"`.
- **Apple silicon only on macOS.** No Intel build is made.
- **Updating from 0.7.0.** 0.7.0 has no in-app updater, so it links to this page: download and run the installer once. From 0.8.0 on, Windows downloads updates in the background and installs them on quit. macOS keeps linking to the release page until the app is signed.
- **Not verified by hand.** None of the result cells in the hands-on real-use checklist (`docs/REAL-USE-CHECKLIST.md`) is filled in:
  - all 23 `real` rows, including the new Telegram section (10.1–10.6). The Telegram link was tested only against a stand-in Bot API, never with a real bot;
  - all 12 `win` rows: installer, tray, notifications, sound, global shortcut, Narrator and the OS theme;
  - the `mac` row (8.3). This version has not been run on a real Mac.

  The 15 `e2e` rows run with fake agents in CI on Windows and macOS, and they pass.

## What's new

### Telegram (optional, off by default)
- **Notifications on your phone.** Pair a bot you make with @BotFather in Settings → Notifications → Telegram. Decisions, results, PRs and errors are sent to your private chat. The token is stored encrypted, and there is a test message.
- **Talk to the Dispatcher from the phone.** Messages from the paired chat go to the Dispatcher, and its answers and the task results come back. Everything else is ignored. Messages sent while the app was off wait until you send or drop them. Commands: `/status`, `/inbox`, `/stop`, `/lock`.
- **Answer decisions with buttons.** Questions with options and plans come with buttons, and a reply answers a question. Answers stay in sync with the in-app inbox. Permissions are answered only on the computer.
- **Photos and files.** Photos and files you send reach the Dispatcher as attachments. They can be up to 20 MB, programs are refused, and the switch is in Settings.
- The poll restarts right after the computer wakes. No port is opened. See the README's Telegram section.

### Accounts and Workers
- **Switch an account off.** In Settings → Accounts, each account can be on, off for an hour, or off. An account that is off gets no new tasks.
- **Fewer idle Workers.** A waiting task gets a Worker only when it starts, and a large context no longer keeps an idle Worker from new work.
- **Right PRs only.** A task records a PR only from its own repository and branch, so a PR it merely cites is no longer tracked as its own.

### Layout and look
- **Top bar across the window.** The left sidebar now starts below a full-width top strip, like the right one. The window buttons share the strip on both systems.
- **Copy buttons.** Saved scripts and code blocks have a copy button. Hovering a running task shows a card with its progress.
- **Settings status at a glance.** The Status group is one line that names what needs attention. It opens to a list with failed checks first.
- **Shots and images.** Before/after screenshots are shown pair by pair, light theme first. Images you attach can be previewed.
- **Fixes.** The usage popover closes when you leave it or press outside. Dialogs no longer pass clicks to the window's drag areas. Attachment chips keep even padding.

### Power and updates
- **Sleep when done.** The moon toggle in the top bar (or asking the Dispatcher) puts the computer to sleep once all work has finished. It is one-shot and off again on every start.
- **In-app updates on Windows.** Updates are downloaded in the background, checked against their checksum, and installed on quit, or at once when nothing is running.

### Under the hood
- **ESLint** with bug-finding rules runs in CI.
- **Screen pictures.** The main screens are compared with reference pictures in both themes on Windows.
