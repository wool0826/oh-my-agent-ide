## Usage rules the checks rely on

- The selected segment of a segmented control always uses text-primary.
- text-tertiary is for static meta text (section headers, timestamps, placeholders, version). It is never a button label; on a selected row it steps up to text-secondary.
- Avatars 1 and 2 are accent-solid and success-solid, checked above.
- Neutral pill.
- Disabled controls (`text-disabled`, 45% opacity) are exempt from 1.4.3 and are not checked.
- Glyphs always sit next to a text label, so status never depends on color alone (1.4.1).
